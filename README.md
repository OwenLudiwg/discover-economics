# 从生活发现经济学

学校食堂两个窗口卖同样的饭，为什么有人看见长队还走过去？从一个日常观察开始，这个中文 AI 学习技能帮你找到值得解释的差异，提出可能的经济学机制，再想办法区分它们。适合经济学入门、课堂讨论，也适合把一时的好奇变成研究问题。

## 拿食堂试一次

> 两个窗口卖同样的饭，为什么有时新来的人也会往长队里排？

一种可能是熟客知道长队所在的窗口出餐快。另一种可能是新来的人不了解窗口，把前面的人当作信息来源，觉得他们的选择值得跟随。两条队伍的长短本身，很难区分这两种解释。

下次去食堂，可以看看同时加入两队的人谁先端到饭。如果窗口速度接近，再观察几天：最早碰巧形成的队伍换了边，后来的人还会跟过去吗？这样的观察能帮你决定下一步问什么。口味、份量和排队位置等差异，也可能影响判断。

## 如何使用

**在普通 AI 对话中**：打开 [技能说明](discover-economics/SKILL.md)，将说明复制到对话中，或者上传这个文件，再说「按这份说明分析我观察到的现象」，接着描述你的见闻。涉及实际制度或研究证据时，选择支持联网核查的对话环境。

**在本地 Codex 中**：从本页的 **Code → Download ZIP** 下载并解压。找到直接包含 SKILL.md 的 discover-economics 文件夹，把整个文件夹复制到你项目的 `.agents/skills/` 下。确认最终路径是 `.agents/skills/discover-economics/SKILL.md`，在该项目内打开 Codex 后输入：

> 用 $discover-economics 分析：为什么老师请大家提问时教室很安静，下课后却有人排队问？

更多安装位置见 [OpenAI 技能文档](https://learn.chatgpt.com/docs/build-skills)。

## 从哪里开始观察

- 同一个人换了场合，为什么做出了不同的选择？
- 一项制度方便了谁，又把等待时间或承担风险的任务留给了谁？
- 我们看到的照片、评分或成功故事，经历过怎样的筛选？

提供你实际看见的细节就够了。技能会把观察和推测分开，说明哪种新观察有助于判断。涉及其他学科时，也会说明经济学能够解释其中哪个环节。
